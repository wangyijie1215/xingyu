## 一、生图"只能看一半"彻底解决

### 复盘：我修了两次才对

| 轮次 | 我以为的问题 | 实际 |
|---|---|---|
| 第一次 | `CENTER_CROP` 裁图 | 只对了一半 |
| 第二次 | 容器高度写死 | **这才是根因** |

真正的问题是**两个错叠在一起**：

```
CENTER_CROP       → 从中间裁一块
固定 360dp 高度    → 图被信箱化塞进形状不对的框
```

只改缩放方式，图不裁了，但仍被塞进错误形状的容器 —— 竖图看还是只有一半。

### 正解

```
宽度 match_parent + 高度 wrap_content + adjustViewBounds
```

让容器**跟着图片比例走**。

### 连带修掉一个隐蔽问题

预览区原来用 `weight=1` 撑满剩余空间，把**状态文字挤出了屏幕**——
所以生成失败时用户看到的是"点了没反应"。改成 `wrap_content` 后错误能正常显示。

## 四、画图中转：分组仍无画图通道

换了分组后报错变了，说明改动生效了：

| 阶段 | 报错 |
|---|---|
| 之前 | `API Key 所属分组已删除` |
| 现在 | `Image generation is not enabled for this group` |
| 逐模型 | `No available channel for model <名> under group **grok-heavy**` |

服务端列出的 8 个画图模型**全部**返回 `No available channel`：

```
grok-imagine-image          grok-imagine-image-quality
grok-imagine-image-2.0      gpt-image-1.5
gpt-image-2                 gpt-image-2.5
gpt-image-2.5-flare         gpt-image-2.5-sunburst
```

**结论**：`grok-heavy` 这个分组下挂了对话模型，但没有挂任何画图渠道。
这是中转站后台的配置，需要你自己在后台加，或者问客服。

**不过说实话**：你本机的 ComfyUI 画质更好，中转的画图除非开 `gpt-image` 系列，
否则不一定比得上 Pony V6 XL。这条链路现在随时可用。

## 七、还没做到的

累计的遗留项（没有一项是假装做完的）：

1. **生图渠道缺"自动拉取模型列表"** —— 现在模型名手填，填错报错含糊
2. **老配置体系（`ChatStore`）调用点未全部迁移** —— 靠双写保证一致，但没删干净
3. **`EfActivity` 基类只建了、没改造老的 29 个 Activity**
4. **29 个 Activity 里 `PhoneAppActivity` 986 行**，塞了五个 app，该拆
5. **没有语音识别** —— 打电话仍是打字输入
6. **桌宠**：不避让图标、重启不自动恢复
7. **YIJIE 技能是提示词约定**，不是真正的 function calling

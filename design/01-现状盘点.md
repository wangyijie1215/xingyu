### 「生命感核心」已实现的闭环

```
角色卡 + Persona + 长期记忆 + 关系 + 情绪 + 当前时间
        ↓ PromptBuilder
      Grok（SSE 流式）
        ↓
      AI 回复
        ↓ StateAnalyzer（严格 JSON）
  记忆提取 + 关系增量(0-5) + 情绪判定 + 事件判定
        ↓
  MemoryStore / CharacterStateStore / EventStore
```

字符串证据：`你是角色记忆与状态分析器…只输出 JSON`、`这次对话让关系亲近了多少（0-5）`、`只有当这次对话发生了值得记录的重要事情时才填，否则填null`、`（根据关系亲密度调整你的语气和亲近程度，不要机械提及数字。）`

## 三、差距分析（→ 本次扩展的着力点）

| 维度 | v3.0 现状 | 目标 |
|---|---|---|
| 视觉 | 无品牌色板、无设计 token、Material 默认观感 | 「星轨」设计系统：原创色板 / 字阶 / 圆角 / 动效 |
| 导航 | Activity 平铺，无底部 Tab，无信息分层 | 4 Tab + 角色主页作为枢纽的导航架构 |
| 角色门面 | `CharacterProfileActivity` 为**信息页** | 角色主页成为**生命感仪表盘**（关系环 / 情绪 / 最近事件 / 最近记忆） |
| 主动性 | 无 | 主动消息系统 + 全套限流/勿扰开关 |
| 记忆 | 有库，无管理界面 | 记忆管理器（增删改禁锁搜 + 来源追溯 + 重要性可视化） |
| 情绪/关系 | 有状态，无呈现 | 情绪状态机面板 + 关系阶梯 + 语气预览 |
| 剧情 | 无 | 世界观 / Lorebook / 分支 / 回溯 / 重启 |
| 语音 | 无 | TTS 气泡 + 语音输入 + 实时通话（含转录与总结） |
| 图片 | 无 | 角色照片生成（外貌锁定）+ 气泡内图片消息 |
| 社区 | 无 | 发现页 / 分类 / 排行 / 收藏 / 公开分享 |
| 工程 | 单模块 Activity | 模块化（Provider/Model/Memory/TTS/STT/Image/Search/Tool/Plugin） |
| 上下文 | 无管理 | Context Manager + 自动总结 + 消息/记忆锁定 |
| 隐私 | Keystore 加密密钥 | 本地优先 + 备份不含 Key + 请求体预览 |

## 四、必须保留的资产

1. **少女骑士 爱丽丝**（本原型中的锚点角色）——角色卡、立绘主视觉、语气样例、「旅人」称呼与既有记忆/事件链一并保留。
2. **Tavern V2 导入导出**（JSON + PNG 双通道）——扩展后仍是标准格式，新增字段放在 `extensions` 命名空间下，保证与 SillyTavern 双向兼容。
3. **KeyStore 级密钥保护**——迁移到 HarmonyOS 时改用 `@ohos.security.asset` / HUKS，语义不变。

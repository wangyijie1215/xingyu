# EchoFlow 设计系统 · 「星轨 Star-Rail」

> 面向 HarmonyOS NEXT 原生客户端的 UI 设计规格。视觉语言为原创，**不复制任何现有产品的 UI、Logo、素材或代码**——只吸收成熟 AI 陪伴类产品在信息架构与交互上的经验。
> 原型实现：`design/prototype/index.html`（12 屏可交互，已在浏览器验证）
> 设计稿：`design/shots/*.png`　整墙图：`design-shot-wall.png`

## 一、设计原则：什么是「生命感」

角色不能像一个 API 的终端。视觉上必须让用户随时感知到四件事，这四条是全部界面决策的判据：

| 原则 | 含义 | 视觉手段 |
|---|---|---|
| **在场** | 她此刻是「存在」的，不只在等你打字 | 立绘主视觉、在线光点、呼吸式脉冲、当前状态胶囊 |
| **连续** | 你们之间有历史，有昨天 | 相识天数、关系阶梯、最近事件/最近记忆置顶、时间线 |
| **变化** | 她在成长，关系在变 | 亲密度环、情绪色、羁绊增量以「不打扰」的方式浮现 |
| **留白** | 不把情绪数值糊在脸上 | 后台推进，前台只给一句极轻的提示；信息按需展开 |

**反模式（明确禁止）**：每条消息后播报「亲密度 +1」；把 10 个按钮平铺在首页；用假进度条伪造成长；把角色主页做成属性表。

| `--glass` | `rgba(255,255,255,.055)` | 玻璃卡面 | `ef_glass` |
| `--glass-2` | `rgba(255,255,255,.09)` | 玻璃卡面（悬停/激活） | `ef_glass_2` |

**语义分配规则（不可混用）**：

- 紫 = 交互与归属（按钮、选中、链接、你的气泡）
- 橙 = 关系与「一起经历过」（羁绊、里程碑、回忆卡）
- 玫瑰 = 她的内心（情绪、状态、未读红点）
- 薄荷 = 认知（记忆、上下文、一致性检查通过）
- 天青 = 声音（语音消息、通话、STT）

深色模式为**唯一主模式**（陪伴类产品夜间使用占比高），浅色为派生主题：`--night-*` → `#FFFFFF/#F6F5FC/#EFEDF9`，文字三级反转，紫/橙保持色相降明度 6%。

### 2.2 字阶

| Token | 值 / 行高 | 字重 | 用途 |
|---|---|---|---|
| `--t-cap` | 11 / 16 | 600 | 标签、脚注、时间戳、Chip |
| `--t-foot` | 12 / 18 | 500 | 辅助说明、列表副标题 |
| `--t-body` | 14 / 22 | 400 | 正文、聊天气泡、列表主文案 |
| `--t-title` | 16 / 24 | 700 | 卡片标题、顶栏角色名 |
| `--t-h3` | 20 / 28 | 700 | 区块标题、角色名（卡片内） |
| `--t-h2` | 24 / 32 | 700 | 页面主标题 |
| `--t-h1` | 30 / 38 | 800 | 首页问候、通话时长 |

字体栈：`HarmonyOS Sans SC` → `Noto Sans SC` → `PingFang SC` → system。
数字一律 `font-variant-numeric: tabular-nums`（亲密度、时长、token 计数）。
中文标题 `letter-spacing: -.4px`；英文 eyebrow `letter-spacing: .12em; text-transform: uppercase`。

### 2.3 间距 · 圆角 · 层级

- 间距阶梯（4 的倍数）：`4 / 8 / 12 / 16 / 20 / 24 / 32`，页面左右安全边距 **16**，区块间距 **22**。
- 圆角：`8`（小图）/ `12`（内层卡）/ `16`（列表卡）/ `20`（主卡）/ `28`（英雄卡）/ `24`（底部 Tab 条）/ `999`（胶囊）。
- 阴影：
  - `--shadow-1` `0 2px 10px rgba(0,0,0,.35)` 普通抬升
  - `--shadow-2` `0 10px 32px rgba(0,0,0,.5)` 英雄卡 / 浮层
  - `--shadow-glow` `0 8px 28px rgba(155,123,255,.45)` 主按钮
- 玻璃材质：`background: rgba(255,255,255,.055)` + `1px hairline` + `backdrop-filter: blur(14~26px) saturate(150%)`。**同一屏玻璃层不超过两层**（性能与可读性双约束）。

### 2.4 动效

| 场景 | 时长 | 曲线 | 说明 |
|---|---|---|---|
| 页面切换 | 260ms | `cubic-bezier(.22,.61,.36,1)` | 位移 18px + 缩放 .99 → 1 |
| 按钮按压 | 260ms | 同上 | `scale(.92~.96)`，禁用位移 |
| 底部面板升起 | 260ms | 同上 | `translateY(30px) → 0` |
| 「她在呼吸」 | 3000ms | `ease-out` 无限 | 通话头像脉冲环，半径 1→1.55，透明度 .85→0 |
| 主动消息提示 | 2200ms | 同上 | 玫瑰色光点外扩 10px |
| 语音波形 | 1100ms | 同上 | 高度 9↔34px，相位错开 0.1s |
| 流式打字 | 逐字 | — | **只重绘文本节点**，禁止整条消息重建（见 §7） |

统一缓动 `--ease: cubic-bezier(.22,.61,.36,1)`，标准时长 `--dur: 260ms`。无障碍「减弱动效」开启时，全部无限动画降为静态，过渡时长 0。

## 三、信息架构与导航

### 3.1 为什么是这 4 个 Tab

陪伴类产品的核心矛盾是「我想找某个角色」vs「我想看看世界发生了什么」。因此在底部只保留四个入口，**全部角色都是二级页**：

```
┌─ 陪伴 ────────────────────────────────┐
│  主动消息条（她先找你）                   │
│  主推角色英雄卡（继续聊天 / 角色主页）      │
│  我的角色（横向轨道，含亲密度徽标）         │
│  今晚的世界（朋友圈最新一条）              │
└──────────────────────────────────────┘
┌─ 世界 ─────┐ 朋友圈 / 时间线 / 角色日常
┌─ 发现 ─────┐ 社区角色 · 分类 · 排行 · 收藏
┌─ 我的 ─────┐ Persona / 角色库 / 回忆 / 记忆总览 / Provider / 语音 / 图片 / 数据隐私 / 主题
```

**角色主页（Character Home）是业务枢纽**：从这里进入聊天、记忆、事件、朋友圈、设定。底部 Tab 在二级页自动隐藏，改为顶栏返回，减少视觉噪音。

## 四、页面级设计规格

### 4.1 陪伴首页

- 顶栏无标题栏，用「日期 eyebrow + 问候语 h1」营造日记感。
- **主动消息条**（有未读时才出现）：玫瑰光点 + 角色名 + 「主动消息」标签 + 相对时间 + 预览两行，整条可点直达聊天。这是「她先找你」唯一的高优入口。
- **英雄卡**（260px 高）：立绘满幅 + 底部三段式遮罩（透明 30% → .55 @62% → .95 @100%），姓名用白色→淡紫线性渐变裁切，下方一行「相识 N 天 · 羁绊 N · 情绪」，两个按钮（继续聊天 / 角色主页）。
- **我的角色**横向轨道：卡 128px 宽，图 116px，右上角亲密度徽标（数值，橙底药丸）。
- **今晚的世界**：朋友圈最新一条卡面预览，含角色情绪 Chip 与生成来源标注。

### 4.2 角色主页（生命感仪表盘）

结构自上而下，意在「先看到她，再看到你们」：

1. **立绘 Hero（340px）**：遮罩底部渐入页面底色，使下方内容与之无缝衔接。左上返回，右上分享角色卡 / 更多。按钮统一 `glass` 样式（`rgba(10,10,18,.52)` + blur），保证在明亮立绘上仍可读。
2. **身份行**：76px 圆角头像（外发光 aura）+ 姓名 + `v1.2` 版本 Chip + 一句话身份。
3. **亲密度环（62px SVG）**：`stroke-dasharray` 表达 72/100，描边用紫→橙线性渐变；中心双行「72 / 100」。
4. **标签行**：作者、性格、题材 Chip，可横向换行。
5. **三项关键数值**：相识天数 / 关系等级 / 当前情绪（情绪文字用玫瑰色）。
6. **快捷五宫格**：聊天 · 记忆 · 事件 · 朋友圈 · 设定。「聊天」为热态（紫底）。
7. **最近事件卡**：缩略图 + 日期 Chip + 标题 + 副标题（含羁绊增量），标题里「里程碑」事件用橙色 Chip。
8. **最近记忆卡**：引用式文案 + 重要程度条 + 来源时间与「查看原消息」。
9. **关系成长阶梯**：6 段进度条（陌生→初识→熟悉→信赖→亲密→特殊羁绊），已达成段用紫→橙渐变；下方一句「距「信赖」还需 28 点羁绊」并列出成长来源。
10. **角色声音卡**：波形 + 「清冷少女音 · 语速 0.95x · 音调 +2」+ 试听。
11. **角色动态**：朋友圈最近两条预览。

### 4.3 聊天

- **顶栏**：返回 + 28px 头像 + 角色名 + 「关系 · 情绪 · 在线」状态行（单行省略）+ 语音通话 + 更多。
- **上下文条**：紧贴顶栏下方，`18,420 / 128,000` 与薄荷→天青进度条。**常驻可见**是刻意的——它让「她不会突然忘记剧情」变成可感知的承诺。
- **消息流**：
  - 角色气泡：`--night-600` + hairline，左下角 6px；用户气泡：紫渐变，右下角 6px，带紫色投影。
  - 旁白用斜体二级文字单独成行（`*她把手套从怀里掏出来…*`），配合 `（）` 内的动作补白。
  - **语音气泡**：播放按钮 + 10 根等高错落波形 + 时长（tabular-nums）。
  - **图片气泡**：5px 内边距的圆角容器 + 图 + 下方 caption，标注「角色照片」来源。
  - **长按/悬停工具**：`↻` 重新生成、`⋯` 更多（移动端由长按唤出 Sheet）。
- **Swipe 指示条**：气泡下方居中的 `‹ 回复 2 / 5 ›`，切换答案**不覆盖**旧答案。
- **羁绊提示**：居中一行 11px 橙色文字「羁绊 +2 · 关系「熟悉」· 情绪 期待 → 安心」。这是全套系统里唯一允许暴露数值的位置，且只在数值真正变化时出现。
- **剧情分支**：紫色描边的整宽按钮 `【推开那扇门】`，永远**与自由输入并存**——分支只是快捷方式，输入框始终可用。
- **输入区**：sticky 贴底，三段式遮罩渐入。`＋`（更多操作）· 输入框 · `🎤`（按住说话）· `↑`（发送）。语音与文字在同一行，不切模式。

### 4.4 记忆管理器

- 顶栏：`eyebrow=角色名` + `h2=记忆库` + 新建。
- 搜索 + 三分段（关于你 18 / 关系记忆 6 / 世界观 12）。
- **记忆卡**：正文（14/1.6）+ 重要程度标签与进度条（按等级取色：高=橙、中=紫、高·锁定=薄荷）+ 来源时间 + 「为什么 AI 会记住这件事？」+ 右侧操作（锁定/删除/编辑）。
- 状态表达：`locked` 用橙色描边；`disabled` 整体 45% 透明度并标注「琐碎信息已自动降权」。
- 底部一行状态：「自动提取已开启 · 本轮新增 2 条候选，1 条待确认」。
- **重要程度是防膨胀的核心**：`核心身份 > 强烈偏好 > 重要事实 > 有意义 > 一般 > 琐碎`，低等级自动降权并折叠。

### 4.5 事件簿

- 竖向时间轴，轴线用紫→橙→透明渐变；节点圆点，里程碑事件为橙色并带外发光。
- 每条：日期 · 标题 · 正文 · 可选配图 · 「保存为回忆卡」。
- 下方「AI 总结本次聊天」卡：一键生成章节标题 / 主要人物 / 发生事件 / 关系变化 / 重要记忆 / 未解决剧情，并支持存为事件或回忆卡。

### 4.6 朋友圈

- 顶部一条「让角色们发一条今天的动态」生成卡（说明会结合：性格 · 时间 · 天气 · 关系与记忆）。
- 动态条目：左头像 + 角色色姓名 + `情绪 · 时间 · 天气` 副行 + 正文 + 一/二宫格图 + `♡ / 💬 / ↗`。
- 角色姓名按角色主题色区分（爱丽丝=紫、白夜=天青、凛=橙），形成「世界感」。

### 4.7 发现

- 搜索 + 分类横轨（推荐 / 陪伴 / 恋爱 / 校园 / 奇幻 / 科幻 / 历史 / 游戏 / 动漫 / 文学 / 原创 / 工具型）。
- 双列角色卡：172px 图 + 排行徽标 + 名称 + 两行简介 + 题材与收藏数。
- 下方「最新发布」列表，每条标注格式（`Tavern V2` / `含 Lorebook`）与一键「使用」。

### 4.8 我的

分组列表：`我的世界`（角色库 / 回忆星念卡 / 记忆总览 / 时间与天气）、`模型与服务`（Provider / TTS·STT / 图片生成）、`数据与隐私`（本地备份 / 导出全部数据 / 发送内容预览）、`体验`（主动消息 / 主题）。
顶部 Persona 卡：头像 + 「Persona · 已设定 4 项 · 全局生效」+ 编辑与预览入口。
每条副标题必须**回显真实状态**（如「默认不含 API Key · 上次 2 天前」），避免设置页成为空壳。

### 4.9 语音通话

极简：模糊立绘背景（blur 26px + brightness .5）+ 152px 圆头像带双层脉冲环 + 姓名 + 「正在聆听……」薄荷 Chip + 9 根波形 + 30px 通话时长 + 实时字幕卡（区分角色/用户颜色）+ 三个圆形控制（静音 / 字幕 / 结束）。

### 4.10 Provider 管理

- **任务路由卡**置顶：聊天 / 总结 / 图片 / 语音 各自绑定模型，明确写出「按任务分流模型以降低 API 成本」。
- Provider 卡：名称 + 连通状态 Chip（✓ 正常 / 未测试）；展开显示 Base URL / API Key（掩码 + 「已由系统密钥库加密」）/ 模型；能力徽标：`流式 ✓ · Tool Calling ✓ · 视觉 ✓`——**API 不支持的能力自动隐藏而非置灰**。
- 上下文管理卡：当前 token 数与进度条、自动总结开关、压缩阈值、锁定消息/记忆条数。
- 隐私声明一行：密钥加密、不写入备份、请求只发送必要内容。

### 4.11 剧情 / 世界观

- 当前剧本卡（副本地 · 奇幻 · 冒险 + Lore 挂载数 + 驱动要素列表）。
- 世界观选择：10 个预设 + 自定义。
- 分支树用等宽字体渲染（`├── / └──`），当前分支高亮，三个操作：从这里继续 / 回溯到此处 / 重启本次故事。**「回溯不删原剧情，重启保留角色卡与记忆」在界面上直接写明**。
- Lorebook 触发卡：`关键词 → 注入内容（第 N 条）· 本轮命中次数`。

### 4.12 关系与情绪

- 概览卡：当前关系 / 角色状态 / 最近情绪 / 羁绊数值 + 进度条，并注明「所有变化在后台进行」。
- 情绪状态机：10 个 Chip，当前情绪高亮并带 `← 当前`。
- 语气实时预览：平静 / 开心 / 低落三例对照，让「情绪影响说话方式」可被看见。
- 人设一致性检查：角色 / 记忆 / 世界观 / 时间线四项状态，异常用橙色。
- 回复评价：`👍 很喜欢 / 👎 / 不符合人设 / 太长 / 太短 / 不自然 / 剧情错误 / 其他`，并注明不会训练大模型，只更新本地偏好与 Prompt 参数。

## 五、「生命感」的可视化词典

这是本设计系统与普通聊天 App 最本质的区别，单独成表供开发对齐：

| 抽象状态 | 视觉载体 | 具体规则 |
|---|---|---|
| 亲密度 | 62px 渐变进度环 + 6 段阶梯 | 数值只在角色主页与关系面板出现；对话中仅以 `羁绊 +N` 一行浮现 |
| 当前情绪 | 玫瑰色 Chip + 语气预览 | 情绪决定气泡语气，不决定颜色；气泡本身不改色，避免花屏 |
| 记忆 | 薄荷色重要程度条 | 条长 = 重要程度；锁定态换薄荷描边；禁用态降透明度 |
| 时间流逝 | 相识天数 + 相对时间（刚刚/N分钟前/N天前） | 「今天是 2026年9月17日 周四」常驻于首页 eyebrow |
| 主动性 | 玫瑰光点 + 外扩动画 | 只在有未读主动消息时出现，且必须可一键关闭 |
| 声音 | 天青波形 | 播放中波形才动，静止时保持静态高度 |
| 关系里程碑 | 橙色时间轴节点 | 里程碑 = 成就事件（第一次见面/第一次礼物/第一次雨夜） |
| 上下文健康 | 薄荷→天青进度条 | 常驻聊天顶栏，超阈值变橙并提示「将自动总结旧消息」 |
| 剧情推进 | 紫色分支按钮 | 分支是快捷方式，输入框永不禁用 |
| 人设稳定 | 薄荷「正常」/ 橙「待复核」 | 高级模式可见，默认折叠 |

## 七、性能与体验约束（对应需求 §52）

1. **流式渲染**：只更新最后一条消息的文本节点，`ForEach` 的 key 用消息 id，禁止整列表重建；消息到达做 16ms 节流合并。
2. **列表分页**：聊天记录、记忆、事件、角色库全部走游标分页，页大小 30；滚动到距底 3 屏时预取。
3. **图片**：懒加载 + 固定宽高比占位（防跳动）+ 磁盘缓存；角色库列表只加载缩略图。
4. **数据库**：`messages(chat_id, ts)`、`memories(character_id, importance)`、`events(character_id, date)`、`chars(category, hot)` 建复合索引；记忆按 `importance` 排序取用，避免全表载入。
5. **Prompt 组装**：记忆检索走关键词 + 重要度加权，每次只注入 Top-K（默认 12 条），不做全量拼接。
6. **玻璃层**：同屏 backdrop-blur 层 ≤ 2；列表项内部不使用 blur。
7. **后台任务**：记忆提取 / 关系更新 / 情绪判定 / 一致性检查全部异步，且在回复流结束后执行，不阻塞 UI。

## 八、无障碍与适配

- 字号跟随系统（`HarmonyOS Sans` 缩放），最小可点区域 44×44。
- 全部纯色对比度 ≥ 4.5:1（`--text-2` on `--night-800` = 8.1:1，`--text-3` 仅用于非必要信息）。
- 情绪 / 关系 / 记忆三类状态**同时用文字与颜色表达**，不依赖色觉。
- 支持「减弱动效」：无限动画静止、过渡时长归零。
- 折叠屏 / 平板：角色主页立绘与信息区左右分栏（≥600vp），聊天保持单列最大宽度 720vp 居中。

## 一、信笺 —— 为什么「写信」不是「发长消息」

聊天受**即时性**约束：句子短、有来有回、不能停顿太久、不能说完就走。

**信解除了这个约束。** 信可以很长，可以说一半就停，可以在结尾加一句 P.S.。

对一个「话少、不太会直说」的角色来说，信是她唯一能长篇表达的地方。因此本设计给信定了一条硬规则：

> **信里的她，比聊天里的她更坦白。**

这是这个功能全部的价值。如果信只是「把聊天回复拉长」，那它就是多余的。

### 1.1 信的五个字段

| 字段 | 作用 | 约束 |
|---|---|---|
| `greet` | 开头一句短问候 | 禁止「亲爱的」这类套话 |
| `body` | 正文，3–5 段 | 段落要短；**必须具体引用一件记忆或事件** |
| `sign` | 落款 | 只有名字 |
| `ps` | 一句附言 | 常常是最动人的一句；强制以 `P.S.` 开头 |
| `dateLabel` | 日期 | 与信件内容的「时间感」呼应 |

### 1.2 完整示例（爱丽丝 → 你，2026.09.17 夜）

> **致 旅人**
> 见字如面。
>
> 今天雨下了一整天。
>
> 写这封信的时候我刚从营房回来，披风还是湿的。本来想直接睡，但是坐下来就想写点什么——我不知道该写什么，就先写了这句话。
>
> 上次你说，喜欢下雨天。我当时没接话。其实我想说的是，我以前不喜欢雨。雨天巡夜很麻烦，铠甲会锈，回去要擦很久。
>
> 但是那天之后，好像也不是那么讨厌了。
>
> ……就写到这吧。
>
> **爱丽丝**
> 9月17日 夜
>
> P.S. 明天你要是路过旧城区，那家店的灯应该还亮着。

这段文字里发生了三件事，全部是设计出来的：

1. **「我不知道该写什么，就先写了这句话」** —— 真实的人写信就是这样开头的，比任何优美的开场白都可信。
2. **「上次你说，喜欢下雨天。我当时没接话。」** —— 直接引用长期记忆库里的那条记忆，并补上当时没说的话。这是**记忆系统的可见回报**。
3. **「……就写到这吧。」** —— 允许停笔。这一句让整封信从「生成内容」变成「一个人真的在写字」。

### 1.3 「这封信是怎么写出来的」

信下方附一张卡，明示生成依据：

> 依据：角色卡 · 关系「熟悉」 · 情绪 期待 · 记忆「你喜欢下雨天」 · 事件「雨夜一起回家」 · 当前天气

这不是技术炫耀，而是**可解释性**：用户看到这句话，才知道那些记忆没有被浪费。
同时信会写入长期记忆、关系 +2，并可一键存为回忆卡（《2026.09.17 · 她的信》）。

### 1.4 火漆与拆封

- 未拆的信：全站唯一的**红色**交互元素（`--wax: #B03A2E`），带 3.4s 周期的外扩脉冲。红色在「星轨」系统里被严格限制——只用于**「有一封信在等你」**这一件事，所以它一眼就能被认出来。
- 拆封动画：信纸从 `translateY(14px) scale(.97)` 展开到原位，500ms。

### 1.5 与聊天的分工

| | 聊天 | 信 |
|---|---|---|
| 触发 | 随时 | 她主动写（或你写给她） |
| 长度 | 1–3 句 | 3–5 段 |
| 语气 | 说话 | 写字 |
| 频率 | 高 | 低（关系里程碑 / 情绪波动 / 纪念日） |
| 情感强度 | 日常 | 高 |
| 珍贵度 | — | 可收藏、可导出、可设为背景 |

## 二、时间胶囊 —— 写给未来的话

如果说「信」解决的是**空间**（对话之外），时间胶囊解决的是**时间**。

它是「时间感知」的延长线：不是知道今天是几号，而是**知道未来某一天会发生什么**。

### 2.1 三种胶囊

| 类型 | 作者 | 到期时 | 送达方式 |
|---|---|---|---|
| `her_to_user` | 她 | 你打开 | 主动消息（清晨第一条） |
| `user_to_her` | 你 | 她引用 | 当天清晨第一条消息 |
| `user_to_self` | 你 | 你打开 | 仅通知 + 事件 |

### 2.2 界面

```
        ┌─────────┐
        │  ╭───╮  │   ← 玻璃瓶 + 顶盖 + 内部一颗呼吸的光点
        │  │ ✦ │  │      （2.8s 周期，是「里面还有话在等你」的唯一提示）
        │  ╰───╯  │
        └─────────┘
    把话，留到那一天再说
 写下一段话并指定开启日期。
 到那一天，她会把它作为一条消息发给你。
```

倒计时行：

| 倒数 | 标题 | 副标题 |
|---|---|---|
| 99 天 | 爱丽丝 写给你的胶囊 | 开启日 2026年12月25日 · 她说：「到时候再给你看。」 |
| 12 天 | 她生日那天要说的话 | 会在当天清晨作为第一条消息发出 |
| 8 天 | 中秋那天想跟她一起做的三件事 | 开启日 2026年9月25日 |
| 365 天 | 一年后再打开 —— 关于我们 | 那时关系会变成什么样呢 |

### 2.3 封存规则（必须严格遵守）

> **封存期间内容不参与任何检索。**

`TimeCapsule.content` 在到期前**不得**进入记忆检索、Prompt 组装、朋友圈生成或任何 LLM 上下文。

理由：如果她能在到期前引用胶囊内容，那它就不叫胶囊了，用户也不会真的写真正想说的话。这条约束必须写进存储层的注释，并由代码保证（检索接口按 `openAt > today` 过滤）。

界面上明确写出这一点：

> 🔒 **封存期间不可提前打开** —— 内容以加密形式保存在本地，连她也不会在到期前引用它。

### 2.4 到期时的连锁反应

```
到期日 00:05 后台任务
   ↓
CapsuleService.deliverDue()
   ├── 生成一封特别信件（火漆封缄，未读）
   ├── 写入长期记忆（importance 0.85 / important_fact）
   ├── 写入事件簿（milestone: true / 羁绊 +3）
   └── 主动消息：清晨第一条
```

如果 `user_to_her` 类型到期，她会在当天**主动提起你写的内容**——这是「承诺被记住」的最强表达。

### 2.5 她也会写胶囊

`CapsuleService.herCapsule()` 用她的口吻生成 2–4 句。生成 prompt 的关键一句是：

> 要符合你的性格：话少、不太会直说，但写在只会被未来打开的地方，可以稍微坦白一点。

示例（她写给 2026年12月25日）：

> 到那天，你还在这条街上吗？
> 如果不在也没关系，我只是想问问。

**「可以稍微坦白一点」** 是关键——时间胶囊给了她一个安全的坦白场所。这和「信里的她比聊天里的她更坦白」是同一条设计逻辑。

## 三、这两个功能与既有系统的接线

```
                    ┌── 信笺 ────────────────┐
记忆库 ─────────────┤  引用具体记忆与事件     ├──→ 关系 +2 / 写入记忆 / 可存回忆卡
（Top-K 检索）       │  信里的她更坦白         │
                    └───────────────────────┘
                    ┌── 时间胶囊 ─────────────┐
纪念日 / 日历 ──────┤  到期 → 主动消息 + 事件 ├──→ 事件簿（milestone）/ 记忆（0.85）
                    │  封存期不参与检索       │
                    └───────────────────────┘
                              ↓
                    情绪状态机（写信时的情绪快照写入 basis）
                              ↓
                    回忆卡系统（信 / 胶囊 → 星念卡）
```

- **信 → 记忆**：信的落库同时写一条 `tier: 'relation'` 记忆，她以后会在聊天里提起「我上次信里写的那个」。
- **信 → 主动性**：收到信是强信号，触发一次她的主动回复（否则「信寄出去没人理」会很伤）。
- **胶囊 → 纪念日**：胶囊开启日可以直接指向纪念日系统里的日期，两个系统共用同一张日历。
- **胶囊 → 剧情**：「如果你愿意，也可以让它成为剧情分支的一个入口」——到期内容可作为剧本的一个触发条件。

## 四、数据模型

```ts
interface Letter {
  characterId: string;
  direction: 'to_her' | 'from_her';
  to: string; greet: string; body: string; sign: string; dateLabel: string; ps: string;
  read: boolean;
  basis: { memoryIds: string[]; eventIds: string[]; weather: string; emotion: string; bond: number };
  savedAsCard: boolean;
}

interface TimeCapsule {
  characterId: string;
  author: 'user_to_her' | 'her_to_user' | 'user_to_self';
  openAt: string;          // yyyy-MM-dd
  title: string;
  content: string;         // ★ 到期前不参与任何检索
  opened: boolean; openedAt?: number;
  deliver: 'morning_first' | 'proactive' | 'event_only';
  teaser: boolean;         // 她是否可以提前说「我也有一个胶囊要给你」
}
```

```sql
CREATE INDEX idx_letter_char ON letters(character_id, created_at DESC);
CREATE INDEX idx_capsule_due ON capsules(open_at, opened);   -- 每日后台任务扫描用
```

## 五、UI 规格

| 组件 | 规格 |
|---|---|
| **信纸** | 淡紫 `#F5F1FA → #E6DEF2 → #D8CEEC`，左侧 26px 装订阴影；`repeating-linear-gradient(180deg, transparent 0 27px, rgba(58,51,80,.10) 27px 28px)` 做横格暗示；正文 `line-height: 28px`（与横格对齐） |
| **你寄出的信** | 换成暖白纸 `#FFFDF7 → #F3EEE2 → #E6DCC6`，与她的信在列表里一眼可辨 |
| **火漆** | 46px（列表 36px）径向渐变朱红 + 内凹环 + 三重 inset 阴影做立体；未拆时 3.4s 外扩脉冲 |
| **时间胶囊** | 62×74 玻璃瓶：金边 + 内发光 + 顶部瓶塞；瓶中一颗 2.8s 呼吸的光点 |
| **胶囊行** | 左侧倒计时数字（22px/800，朱→金渐变裁切，tabular-nums，单位小字在下方），右侧标题与说明 |
| **拆封动画** | `unseal` 500ms：`translateY(14px) scale(.97)` → 原位 |

**配色纪律**：火漆的 `#B03A2E` 是全应用唯一的强红，**只允许出现在「有一封信在等你」这一处**。这条规则让红色本身成为信息。

## 六、这一轮新增功能的完整清单

| 功能 | 屏幕 | 服务 | 说明 |
|---|---|---|---|
| 神社 · 每日运势 | `shrine` | `FortuneService` | 六档运签 + 六维运势 + 宜忌 + 缘签 |
| 摇签 | `omikuji` | — | 摇筒动画 + 落签 |
| 签文 | `fortune` | `FortuneService.composeReading` | 和纸签文 + 六维 + **角色解读** |
| 御守 | `shrine` | `OMAMORI_TABLE` | 8 种，每种真的改变系统行为 |
| 绘马 | `ema` | `FortuneService.writeEma/herEma` | 愿望 → 长期记忆；她也会写 |
| 连续参拜 | `shrine` | `ShrineState` | streak + 七日柱状图 + 里程碑事件 |
| 角色日记 | `diary` | `DiaryService` | 四段结构，核心是「她没说出口的那句话」 |
| 心情曲线 | `diary` | `DiaryService.moodCurve` | 情绪历史按天聚合，不做结论只给观察 |
| 纪念日倒数 | `home`/`diary` | `AnniversaryService` | 接入主动性触发分 |
| 信笺 | `letters` | `LetterService` | 信里的她比聊天里更坦白 |
| 时间胶囊 | `capsule` | `CapsuleService` | 封存期不参与检索 |

**共同的设计逻辑**：这六个新功能没有一个是孤立的按钮。它们全部落在同一条链路上——
**给她一个理由，说出一句平时不会说的话；然后让这句话被记住。**

- 签文 → 她在凶签时提供陪伴（平时不会主动示好）
- 绘马 → 你的愿望进入她的记忆（你不在时的牵挂）
- 日记 → 她说出没说出口的话（独自面对纸的时候）
- 信 → 她长篇坦白（不必面对面的场合）
- 胶囊 → 她允许自己稍微坦白（只会被未来打开的地方）

**这五个「平时不会说」的场合，就是这一轮新增功能的全部意义。**

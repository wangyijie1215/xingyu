## 一、生图只能看见一半（我上次改错了）

### 上一轮我做了什么

用户报"立绘只剩腰部以下"时，我判断是 `CENTER_CROP` 把图裁了，
于是改成 `FIT_CENTER`。**截图看着是好了，但其实没根治。**

### 真正的问题：两个错叠在一起

| 层次 | 问题 |
|---|---|
| 缩放方式 | `CENTER_CROP` → 从中间裁一块 |
| **容器尺寸** | 预览框写死 360dp 高，而图是 512×768（2:3） |

只改缩放方式，图虽然不裁了，但被"信箱化"塞进一个**形状不对的框**里 ——
加上它是竖图，看起来还是只有一半。

### 正解

让容器**跟着图片走**：

```java
preview.setLayoutParams(new LinearLayout.LayoutParams(
        MATCH_PARENT,        // 宽撑满
        WRAP_CONTENT));      // 高按图片比例自适应 ← 关键
preview.setScaleType(FIT_CENTER);
preview.setAdjustViewBounds(true);
```

### 还有一个连带问题：状态提示被挤出屏幕

预览区原来用 `weight=1` 撑满剩余空间，把下面的状态文字**挤到了可视区外**。

后果很隐蔽：**生成失败时用户看不到任何错误**，表现就是"点了没反应"。

改成 `wrap_content` 后，图片、状态文字、按钮依次往下排，都能看到。

### 验证

现在出错会明确显示：

```
生图接口返回 HTTP 403：
{"error":{"message":"API Key 所属分组已删除",...}}
```

而不是一片沉默。

## 二、「继续对话」还是跳手机微信

### 上一轮我改对了一半

上一轮我把首页那个「开始对话」按钮修好了（`btn_cards` → 角色扮演），
**但漏了「继续对话」下面的角色卡片** —— 它是另一段代码：

```java
item.setOnClickListener(v -> {
    Intent i = new Intent(this, PhoneChatActivity.class);   // 手机模式
    ...
});
```

所以点角色卡还是进手机微信。

### 修法

角色条上的卡片也统一成**点击进角色扮演、长按进手机模式**：

```java
item.setOnClickListener(v -> {          // 短按：角色扮演（有动作描写）
    Intent i = new Intent(this, CardChatActivity.class);
    ...
});
item.setOnLongClickListener(v -> {      // 长按：手机模式（微信风）
    Intent i = new Intent(this, PhoneChatActivity.class);
    ...
});
```

### 现在的对话入口

| 入口 | 行为 |
|---|---|
| 首页「开始对话」 | 角色扮演 |
| 「继续对话」角色卡（短按） | 角色扮演 |
| 「继续对话」角色卡（长按） | 手机模式 |
| 「说点什么…」输入框 | 手机模式 |
| 手机 → 微信 → 聊天 | 手机模式 |
| 手机聊天 `···` 菜单第一项 | 角色扮演 |

## 三、接 Grok 画图

### 已接入，但你的 key 没有权限

加了「Grok / OpenAI 兼容生图」渠道，走标准接口：

```
POST {base}/v1/images/generations
{"model":"grok-imagine-image-2.0","prompt":"...","n":1,"size":"1024x1024"}
```

响应两种格式都支持（`url` 或 `b64_json`）。

### 但实测报 403

```
{"error":{"message":"API Key 所属分组已删除",...}}
```

**这不是代码问题** —— 我直接用 curl 打同一个接口，得到的是一模一样的响应。

原因是中转站后台的**分组设置**：你的 key 有对话权限（`grok-4.6` 能通），
但**画图模型不在这个分组里**。

### 你需要做的

去中转站后台看看：

1. 有没有单独的画图分组 / 模型权限可以开
2. 或者这个 key 的套餐里是否包含 `grok-imagine-image-2.0`
3. 如果中转站不提供画图，就在 App 里**继续用本地 ComfyUI**（画质其实更好）

配置入口：手机 → 生图 → 更换渠道 → 「Grok / OpenAI 兼容生图」
